# Design-system package boundary

This package will contain accessible primitives, semantic CSS tokens, typography, icons, and documented interaction states built with Tailwind/Radix where justified. It does not own scenario state, map layers, evidence logic, or page workflows.

Components require keyboard behavior, focus treatment, contrast, reduced-motion behavior, and test/demo states. The visual direction is defined in [the UI specification](../../docs/product/ui-design.md).

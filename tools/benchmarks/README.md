# Benchmark boundary

This directory will contain benchmark harnesses, reference workload manifests, result schemas, and small reviewed summaries. Large raw output belongs in external artifact storage with checksums and retention.

Every benchmark records commit/build, runtime, hardware/OS/architecture, power settings where relevant, dataset/model/seed, command, cache state, warmup, repetitions, distribution, and limitations. Targets in [performance documentation](../../docs/engineering/performance.md) remain hypotheses until a result meets this protocol.

The first measured baseline is the [Phase 1A Toronto graph import](results/phase1a-toronto-graph-import.md). Its JSON file is generated by the benchmark harness and is the authoritative result; the Markdown file is a reviewed rounded summary.

The [Phase 1B Toronto routing baseline](results/phase1b-toronto-routing.md) measures Dijkstra and A* over fixed-seed endpoints. Its JSON is authoritative and intentionally records the no-commit repository state and experiment limitations.

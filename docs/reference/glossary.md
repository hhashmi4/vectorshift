# Glossary

- **Access grant:** scoped, expiring authority for an anonymous or identified actor to use a scenario/result.
- **Butterfly Effect Mode:** evidence view relating an intervention to supported downstream network changes.
- **Command ID:** unique client-supplied mutation identity used for safe retry and payload-confusion detection.
- **Coordinator epoch/fencing token:** monotonic authority value that rejects stale writers or workers.
- **Demand:** synthetic, versioned trips or flows used as simulation input; not observed traffic unless explicitly sourced and licensed in a future scope.
- **Event sequence:** coordinator-assigned monotonic stream position used for ordering and gap detection.
- **Graph version:** immutable directed, turn-aware network publication with schema and provenance.
- **Map version:** immutable visual/data asset release bound by a manifest.
- **Run manifest:** immutable canonical description of all semantic inputs and resource/output policy for a simulation.
- **Scenario revision:** monotonic version of authoritative scenario command state.
- **Snapshot watermark:** revision/event position included in an immutable scenario snapshot.

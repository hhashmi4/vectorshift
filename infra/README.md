# Infrastructure boundary

This directory is reserved for reviewed declarative infrastructure and container build definitions. It does not authorize provisioning. Phase 0 creates documentation only; no paid service exists.

Read the local [AGENTS.md](AGENTS.md) and [operations design](../docs/engineering/operations.md). Every infrastructure change needs purpose, ownership, environment scope, permissions, data classes, cost impact/ceiling, observability, failure mode, and rollback.
